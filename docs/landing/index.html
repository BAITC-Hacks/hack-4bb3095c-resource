Обоснование в каждой строке

Расчёт учитывает то, что меняет заказ

Рекомендация строится из истории и текущих условий пополнения, а не из одной средней цифры.

Сезонность и устойчивый рост

Сезонный профиль используется при подтверждённой повторяемости; рост — когда он устойчив.

Упущенный спрос

Периоды отсутствия товара учитываются при оценке спроса на артикул.

Разовые крупные заказы

Выбросы отделяются от регулярной потребности, чтобы разовая отгрузка не стала прогнозом.

Товары в пути

Ожидаемые поставки вычитаются из потребности, если приходят в пределах горизонта заказа.

Кратность и MOQ

Рекомендованное количество округляется с учётом минимальной партии из справочника.

Излишки в ₸

Отдельный список показывает запас сверх прогноза и страхового запаса.

AI-ассистент закупщика

Отвечает только на основе данных расчёта и готовит черновик письма. Заказы не отправляет.

Причина рекомендации

Сезонность, рост, остаток, в пути и другие факторы собраны в обосновании позиции.

Свои данные по шаблону

Можно загрузить Excel с данными своей компании по шаблону.

Частые вопросы

Перед первым заказом

А если прогноз ошибётся?

Помесячный спрос по отдельным артикулам шумный. Поэтому сезонность используется только при подтверждённой повторяемости, а заказ объясняется по строкам и может быть скорректирован менеджером. В проверке на отложенных месяцах WAPE составил 36,2% у IEK и 32,2% у Systeme Electric; базовое среднее за 12 месяцев — 36,8% и 30,3% соответственно.

Нужна интеграция с 1С?

Нет. Сервис работает с выгрузками Excel. Готовый заказ можно выгрузить в Excel для загрузки в 1С.

Отправит заказ без меня?

Нет. Сервис готовит расчёт и файл. Заказ утверждает ответственный человек; автоматической отправки поставщику нет.

Работает для других компаний?

Да. Можно загрузить свои данные в одном Excel-файле по шаблону.
