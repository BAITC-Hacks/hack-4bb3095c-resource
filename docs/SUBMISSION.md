# Текст для формы «Сдать решение»

**Название:** Автозаказ ЕКТ — расчёт заказов поставщикам за секунды

**Описание:**
Сервис для менеджера закупа ТОО «Электрокомплект»: по выгрузкам 1С (продажи по документам, остатки, товары в пути,
кратность/MOQ) рассчитывает рекомендованный заказ по каждому артикулу, группирует по поставщикам (IEK, Systeme
Electric) и объясняет каждую строку. Учитывает сезонность и устойчивый рост (только при подтверждённой повторяемости),
восстанавливает упущенный спрос в периоды отсутствия товара, исключает разовые крупные заказы из регулярной
потребности, округляет до кратности, приоритизирует по риску дефицита, показывает излишки в ₸ и ABC.
Менеджер правит «К заказу», вводит ФИО в поле «Кто утверждает (ФИО)», нажимает «Утвердить заказ» или «Выгрузить заказ для 1С (Excel)»; автоотправки нет.

Проверено на реальных данных: бэктест во вкладке «Машина времени» с 01.03.2026 — случаи «нет на складе» у IEK −54% при запасе
−5%, у Systeme Electric −72%; заголовок «Кривая выбора: сколько стоит каждый процент сервиса» показывает цену каждого процента сервиса в ₸. AI-ассистент
(OpenAI, function calling) отвечает на вопросы только по данным расчёта и готовит черновик письма поставщику.
Любая компания может загрузить свои данные по шаблону. 30 автотестов, включая проверки всех must-have ТЗ.

Запуск: `./run.sh` (macOS/Linux) или `run.bat` (Windows) → http://localhost:8501. Ключ OpenAI не обязателен.
